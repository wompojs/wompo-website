## Percorsi consigliati {#percorsi-consigliati}

Inizia da <a href="/docs/guides/quick-start">Quick start</a> se vuoi capire il modello mentale. Poi passa a <a href="/docs/guides/styling">Styling</a> e <a href="/docs/guides/custom-hooks">Custom hooks</a> quando inizi a creare componenti riutilizzabili.

## Cosa costruirai {#cosa-costruirai}

- Un componente con props, eventi e stato.
- Una piccola Todo app con stato derivato e componenti annidati.
- Componenti con CSS locale, CSS modules e Shadow DOM quando serve.
- Hook personalizzati composti sopra gli hook base.
