## Componenti disponibili {#componenti-disponibili}

Wompo espone componenti utili per pattern comuni. Il più importante è <a href="/docs/components/suspense">Suspense</a>, che permette di mostrare una UI alternativa mentre un componente asincrono sta preparando il contenuto.
